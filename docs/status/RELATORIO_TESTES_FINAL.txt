PROBLEMAS ENCONTRADOS E RESOLVIDOS
================================================================================

[RESOLVIDO] POST /api/fretes - Permissoes invertidas
            - Problema: Apenas motoristas podiam postar
            - Causa: Logica de negocio incorreta
            - Solucao: Alterado para apenas shippers
            - Status: CORRIGIDO E TESTADO

[RESOLVIDO] Circular imports no backend
            - Problema: Modules nao conseguiam carregar
            - Causa: auth.py e fuel_station.py importavam um ao outro
            - Solucao: Comentado import nao-essencial
            - Status: CORRIGIDO

[RESOLVIDO] Pydantic v2 - Deprecated "regex"
            - Problema: schemas usavam regex= (Pydantic v1)
            - Causa: Versao do Pydantic atualizada
            - Solucao: Alterado para pattern=
            - Status: CORRIGIDO

[RESOLVIDO] CORS - Frontend e Backend em portas diferentes
            - Problema: localhost:3009 nao permitido
            - Causa: CORS whitelist desatualizado
            - Solucao: Adicionado localhost:3009 a whitelist
            - Status: CORRIGIDO
