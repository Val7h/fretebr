================================================================================
FLUXO DO CHAT
================================================================================

1. Motorista faz proposta em um frete
2. Shipper aceita a proposta
3. Match status muda para "aceito"
4. Ambos podem acessar /match/:id (MatchDetailPage)
5. Clicam em "💬 Conversar"
6. Redirecionados para /match/:id/chat (ChatPage)
7. Ambos veem histórico de mensagens
8. Podem escrever e enviar mensagens
9. Mensagens atualizam em tempo real (2s polling)
10. Podem deletar suas próprias mensagens

================================================================================
ENDPOINTS DE CHAT
================================================================================

🔹 GET /api/messages/match/{match_id}
   Listar todas as mensagens de um match
   Apenas participantes podem acessar
   Retorna: { mensagens: [], total: int }

🔹 POST /api/messages/match/{match_id}
   Enviar uma mensagem
   Body: { conteudo: string (max 2000 chars) }
   Apenas participantes podem enviar
   Chat disponível apenas se match status = "aceito"

🔹 DELETE /api/messages/{message_id}
   Deletar uma mensagem
   Apenas o autor pode deletar
   Retorna: { message: "Mensagem deletada com sucesso" }

Frontend (React):
const handleSendMessage = async (e: React.FormEvent) => {
  e.preventDefault();
  if (!novaMsg.trim()) return;

  try {
    setEnviando(true);
    await apiService.sendMessage(matchId, novaMsg.trim());
    setNovaMsg('');
    await loadMessages(); // Recarrega imediatamente
  } catch (err) {
    setErro(err?.response?.data?.detail);
  } finally {
    setEnviando(false);
  }
};

Backend (FastAPI):
@router.post("/match/{match_id}")
def create_message(
    match_id: int,
    message_data: MessageCreate,
    db: Session = Depends(get_db),
    current_user: User = Depends(get_current_user)
):
    # Validações
    if not message_data.conteudo.strip():
        raise HTTPException(status_code=400, detail="Mensagem vazia")

    # Verificar permissão
    match = db.query(Match).filter(Match.id == match_id).first()
    if match.status != "aceito":
        raise HTTPException(status_code=400, detail="Chat disponível apenas após aceitar")

    # Criar e salvar
    message = Message(
        match_id=match_id,
        sender_id=current_user.id,
        conteudo=message_data.conteudo.strip()
    )
    db.add(message)
    db.commit()
    db.refresh(message)

    return message
