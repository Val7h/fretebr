- [ ] Experience com 100+ motoristas/drivers
- [ ] Knowledge de compliance/regulações (ANTT, DETRAN)
- [ ] Implementação de SLAs em ambientes complexos

✅ NICE-TO-HAVE:
- [ ] Experiência com startups (ágil, resourceful)
- [ ] Conhecimento de seguros/parceria com seguradoras
- [ ] Track record de escalação (50 → 5.000 motoristas)
- [ ] Expertise em technology + operations

❌ RED FLAGS:
- [ ] Só corporate experience (sem startup DNA)
- [ ] "Isso vai demorar 6 meses pra regulação" (slow)

- [ ] Sem disponibilidade de tempo (precisa full-time)

## 📊 PROCESSO DE SELEÇÃO

### Round 1: LinkedIn Screening (30 min)

```
1. Ler perfil + recomendações
2. Verificar track record
3. Passar short 5-min video pitch
4. Se score >7/10 → Round 2
```

### Round 2: Call Inicial (30 min)

```
1. Apresentar FreteBR
2. Explicar a oportunidade
3. Entender motivações deles
4. Q&A
5. Se aligned → Round 3
```

### Round 3: Entrevista com Fundador (60 min)

```
1. Deep dive em expertise
2. Discutir termos (equity, salary, timeline)
3. Alinhamento cultural
4. Decision dentro 1 semana
```
