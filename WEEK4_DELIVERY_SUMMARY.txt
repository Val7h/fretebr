DEPLOYMENT INSTRUCTIONS
================================================================================

1. Set Environment Variables
   cp .env.example .env
   Edit .env with real Mercado Pago credentials

2. Build Docker Images
   docker-compose build

3. Start Services
   docker-compose up -d

4. Run Migrations
   docker-compose exec backend alembic upgrade head

5. Verify Health
   curl http://localhost:8000/health

6. Configure Webhook (in Mercado Pago dashboard)
   URL: https://yourdomain.com/api/webhook/mercado-pago
   Secret: Add to .env as MERCADO_PAGO_WEBHOOK_SECRET

7. Test End-to-End
   See E2E_PAYMENT_TEST_GUIDE.md
