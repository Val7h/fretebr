## 🎯 O PROBLEMA

FreteBR é um marketplace de fretes inovador, mas está **crescendo lentamente** via canais tradicionais (marketing digital = CAC R$ 500).

Descobrimos que **postos de combustível são um canal de aquisição inexplorado:**

```
CAC tradicional:      R$ 500
CAC via postos:       R$ 20
Redução:              -96%

LTV/CAC tradicional:  12x
LTV/CAC via postos:   300x
```

Temos **uma oportunidade de ouro** para crescer exponencialmente.

## 💡 A SOLUÇÃO

Integração estratégica com **postos de combustível** como canais de aquisição:

```
Frentista no posto: "Você trabalha com transporte? 
                    Quer ganhar 3% desconto + comissão?"

Motorista se cadastra: +R$ 10 para frentista
Motorista completa frete: +R$ 10 para frentista

```
